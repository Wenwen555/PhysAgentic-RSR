# Legacy object-space models only

`legacy_object_space/oracle/` and `legacy_object_space/reconstructed/` preserve the earlier **Object-Space M0–M2** door-hinge experiment models. They support `src/active_sysid/backends/`, `identification/`, and the legacy Probe loop.

The **current Robot-Space mainline** no longer uses these MJCF files. Current independent Sim models live under `assets/reconstructed_sim/`; the original double-door World lives under `assets/reference_world/`. The Panda single-door execution fixture lives under `assets/fixtures/`.
